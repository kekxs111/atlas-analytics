# ATLAS – Speichern (ganz einfach)

Keine Accounts, keine API-Keys.

## Depot behalten
1. In der App links **Datei speichern** tippen
2. Die Datei liegt auf deinem Handy/PC
3. Später: **Datei wieder laden**

## Alternative
Unter „Oder: Code kopieren“ den Code in Notizen speichern und später wieder einfügen.
